# MCSA Control Center

Windows Administration Toolkit

## About

MCSA Control Center is a Windows
administration toolkit built with
PowerShell and Batch.

## Features

- Network Management
- DNS Management
- DHCP Management
- Active Directory
- Group Policy
- Windows Firewall
- IIS Management
- Hyper-V Management
- Storage Management
- Windows Services
- Security Tools
- System Diagnostics
- Troubleshooting
- System Administration

## Purpose

Designed for Windows administrators,
IT students, server labs, and
power users.

The project provides a centralized
interface for Windows administration
and troubleshooting.

## Requirements

- Windows 10 / 11
- PowerShell
- Administrator privileges

## Usage

Run the BAT file as Administrator.

Select the required option from
the administration menu.

Always review commands before
executing system changes.

## Development

This project is under active
development.

Future updates may include new
administration modules, networking
tools, diagnostics, security tools,
and automation features.

## Disclaimer

Use this toolkit responsibly.

Some operations may change Windows
configuration, services, networking,
security settings, or system files.

Test commands in a safe environment
before using them on production
systems.
